**QueryMate** is my Final Year Project that uses **Retrieval-Augmented Generation (RAG)** to automate academic query resolution for university students.

Students receive instant AI-generated answers while complex cases are automatically escalated to department staff through an admin portal.

---

- 🤖 AI Chatbot
- 📚 Knowledge Base
- 🔎 Retrieval-Augmented Generation (RAG)
- 👨‍🎓 Student Mobile Application
- 💻 Admin Dashboard
- 📱 WhatsApp Integration
- 🔐 Authentication
- 📈 Query Analytics
